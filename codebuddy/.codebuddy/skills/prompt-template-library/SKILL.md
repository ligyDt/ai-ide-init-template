# Prompt 模板库

## 流程

1. 明确模板服务的任务类型、使用角色、输入字段、输出格式和停止条件。
2. 检查现有项目规则、上下文、记忆和错误免疫库，避免模板与已确认约定冲突。
3. 将模板拆成“目标、上下文、约束、交付物、验收标准、禁止事项”六段。
4. 对涉及外部服务、真实数据、支付、部署或生产访问的模板加入审批提示。
5. 输出可复制模板，并说明适用场景、必填字段和不适用场景。

## 输出

- 模板名称与使用场景
- 标准输入字段
- 推荐提示文本
- 输出格式
- 风险与审批提醒


## 停止条件

缺少目标、范围、运行环境或高风险授权时，先澄清或输出待确认事项，不擅自接入外部写入、支付、部署或生产资源。
