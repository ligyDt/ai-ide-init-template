# CodeBuddy Plan Mode 目录

CodeBuddy Plan Mode 会在完成后将计划自动保存为 Markdown 文件，位于 `.codebuddy/plans/`。这些计划可以作为项目知识库复用，帮助后续对话快速理解历史需求、技术方案和任务拆解。

建议使用 Plan Mode 的场景：

- 新功能从零实现，需要明确技术选型、架构设计和实现路径。
- 多文件协同修改，需要统一方案指导。
- UI、UX、视觉和交互设计，需要先审阅方案再编码。
- 存量项目改造，需要理解既有架构并符合项目规范。
- 复杂任务拆解，需要把大型需求拆成可执行步骤。

不建议把真实凭据、生产地址、真实用户数据或外部账号授权细节写入 Plan 文档。涉及支付、发布、部署或生产访问时，先完成安全审查。
