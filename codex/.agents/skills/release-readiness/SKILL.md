# 发布准备审查

确保变更在获得授权的环境中可部署、可观察、可回退。

## 流程

1. 确认目标环境、发布范围、变更内容、风险等级和批准人；默认仅处理非生产环境。
2. 定义构建产物、配置注入、迁移步骤、部署顺序、健康检查与回滚触发条件。
3. 规划日志、指标、追踪、告警和发布后观察窗口。
4. 涉及云平台、监控平台或新连接器时调用 `$integration-onboarding`；涉及生产、数据或权限风险时调用 `$security-risk-review`。
5. 在外部写入、镜像推送、部署执行、服务开通或生产访问前请求明确批准。

## 输出

- 环境与授权边界
- 发布及回滚步骤
- 非生产验证清单
- 可观测性和告警要求
- 待审批动作列表

## 停止条件

未确定供应商、环境权限或审批边界时，仅给出准备方案，不执行实际部署或外部资源变更。
