# 体验规格设计

为用户界面与交互工作提供工程可以实施、质量可以验证的依据。

## 流程

1. 获取目标用户、任务目标、业务规则、支持终端和成功标准。
2. 描述主流程、分支流程、空状态、加载状态、错误状态和恢复路径。
3. 定义信息层级、页面或视图结构、关键组件、交互反馈与视觉原则。
4. 明确键盘操作、对比度、语义结构、辅助技术、响应式和多语言等可访问性要求。
5. 若需要 Figma 或 Canva 等外部设计工具，先确认非生产目标资产及写入授权。

## 输出

- 用户流程与页面结构
- 交互状态和反馈规则
- 视觉与响应式原则
- 可访问性检查点
- 可由前端和质量验证的体验验收项

## 停止条件

缺少目标用户、关键任务或外部设计资产权限时，先补齐信息，不生成不可验证的精确视觉承诺。
