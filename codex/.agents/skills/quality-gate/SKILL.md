# 质量门禁检查

以证据判断交付是否满足已确认的行为和风险要求。

## 流程

1. 读取需求验收标准、体验规格、架构决定、变更范围和安全限制。
2. 将测试覆盖组织为正常流程、边界输入、错误恢复、权限与数据安全、兼容性和运维验证。
3. 检查现有自动化测试、静态检查、构建结果和人工验证证据，指出缺失覆盖。
4. 按严重程度列出缺陷与风险，给出复现方式或所需证据。
5. 输出门禁结论：通过、附条件通过或阻断，并明确解除阻断所需工作。

## 输出

- 验收与测试矩阵
- 已验证证据和缺口
- 回归风险与缺陷列表
- 发布门禁结论

## 停止条件

没有验收标准或没有足够验证证据时，不宣称交付可发布。
