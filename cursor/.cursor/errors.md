# 错误免疫库

> 每次解决可复发问题后追加记录。记录根因和预防措施，不记录真实凭据、用户隐私或生产资源细节。

## 记录格式

```markdown
## [ERR-001] 错误标题

**首次发生**：YYYY-MM-DD  
**文件/模块**：`path/to/file`  
**错误现象**：  
**根本原因**：  
**解决方案**：  
**预防措施**：  
**关联规则**：
```

## 通用高频问题种子

### [ERR-GEN-001] 环境变量缺失导致本地启动失败

**根本原因**：项目依赖未文档化，或 `.env.example` 与实际读取项不一致。  
**解决方案**：补齐脱敏示例、启动说明和启动前检查。  
**预防措施**：新增配置项时同步更新文档与验证脚本。

### [ERR-GEN-002] 外部服务误连生产环境

**根本原因**：环境名称、账号权限或资源标识未在执行前确认。  
**解决方案**：停止操作，切换到已授权非生产环境，并记录验证边界。  
**预防措施**：所有外部写入、支付、部署和生产访问必须执行前单独确认。

### [ERR-GEN-003] 依赖升级引入破坏性变更

**根本原因**：未阅读迁移说明，缺少回归测试或锁文件审查。  
**解决方案**：回退或补齐迁移适配，运行相关回归检查。  
**预防措施**：核心依赖大版本升级必须先形成影响评估。
