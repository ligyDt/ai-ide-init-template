# 产品需求收敛

1. 阅读 `AGENTS.md` 和现有项目状态，区分事实与待决定事项。
2. 明确目标用户、问题、价值、输入输出、范围内外、运行约束和成功指标。
3. 对外部系统、真实数据、支付、发布或生产访问列出审批要求。
4. 输出需求基线、风险清单和可验证验收标准；需跨职责交付时应用 `delivery-orchestration`。

目标、范围或高风险授权未明确时，不开始业务实现或外部写入。
