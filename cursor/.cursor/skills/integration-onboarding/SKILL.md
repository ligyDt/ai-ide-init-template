# 集成接入管理

1. 明确能力、角色、目标环境、读写范围、账号归属、费用和验证方式。
2. 公开 OpenAI 文档使用 `openaiDeveloperDocs`；其他连接按非生产优先、只读优先管理。
3. 凭据只通过环境变量或授权存储提供，不进入仓库或对话。
4. 外部写入、授权变更、支付、发布、部署与生产访问需逐项批准。
5. 输出模板声明、本机可用性、授权状态与验证结果，不隐瞒未接入事项。
