# 后端与数据规则

- 新增或修改 API 前，明确调用方、输入输出、错误码、鉴权方式、幂等要求、兼容性和回滚方式。
- 新增数据模型、迁移脚本或跨服务依赖时，必须说明数据来源、隐私等级、保留策略和失败补偿方式。
- 外部服务接入先使用 `integration-onboarding`，记录权限、速率限制、成本、测试环境和最小可用验证。
- 涉及敏感数据、支付、生产资源或合规边界时，先调用 `security-risk-review`。
- 交付前给出后端验证证据：单测、集成测试、契约测试、迁移验证、回滚演练或只读探测结果。
