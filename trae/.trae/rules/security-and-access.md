# 安全与访问边界

- 禁止向仓库、对话、规则、命令、Skill 或示例文件写入真实令牌、密码、Cookie、私钥、生产连接串、真实域名、真实用户数据和生产标识。
- 默认仅允许在团队已有非生产环境中进行只读验证。
- 外部写入、账号授权、付费能力、支付、发布、部署、真实数据处理、基础设施变更或生产访问，必须先取得明确批准。
- 接入 MCP、插件、浏览器、设计工具、GitHub、任务系统或云服务时，先记录用途、权限、数据范围、最小验证方式和回滚方式。
- Stripe、支付网关和财务相关流程仅允许测试模式验证；真实付款、退款、订阅变更和财务数据访问必须另行审批。
- 如果任务需要突破上述边界，先停止实现并输出风险、替代方案和需要用户确认的具体动作。
