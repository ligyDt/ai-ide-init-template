# Git Commit Message 规则

- 使用中文说明变更意图，必要的代码标识、文件路径和工具名保持原文。
- 优先使用 `type(scope): summary` 结构，例如 `docs(trae): 补充原生规则与命令配置`。
- summary 使用一句话说明结果，不写泛化的“更新代码”“修复问题”。
- 正文只列关键行为变化、验证结果和风险边界，不粘贴密钥、日志中的敏感值或大段生成内容。
- 如果变更包含配置、安全、发布、外部连接或数据访问调整，正文必须说明影响范围和人工确认项。
