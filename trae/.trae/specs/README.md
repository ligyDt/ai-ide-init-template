# TRAE Spec 工作流目录

TRAE SOLO 的 `/spec` 工作流会在本目录下按任务名称创建子目录，并生成：

- `spec.md`：系统级需求大纲、范围、约束和设计方向。
- `tasks.md`：可执行任务拆解和进度状态。
- `checklist.md`：验收清单和质量门禁。

适合使用 `/spec` 的场景：

- 从零搭建新系统或新模块。
- 大规模重构、架构迁移或跨模块依赖调整。
- 多人协作项目，需要把 Spec 作为单一事实来源。
- 核心业务、支付、安全、权限等高稳定性功能。
- 需要长期维护并保留决策上下文的项目。

首次生成 Spec 文档后，先人工确认或修改文档，再进入实现。
