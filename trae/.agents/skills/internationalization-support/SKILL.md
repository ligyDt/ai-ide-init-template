# 多语言与 i18n 支持

## 流程

1. 明确目标语言、地区、时区、日期格式、数字格式、货币格式和默认回退语言。
2. 检查现有 i18n 框架、文案目录、设计稿和无障碍要求。
3. 将用户可见文案从代码逻辑中分离，避免拼接式翻译和硬编码地区假设。
4. 对支付、法律、隐私、通知和错误提示文案标记为需要人工或法务复核。
5. 输出文案键名规范、资源组织方式、测试点和人工验收清单。

## 输出

- 语言与地区范围
- 文案资源结构
- 格式化规则
- 可访问性与回退策略
- 人工复核项


## 停止条件

缺少目标、范围、运行环境或高风险授权时，先澄清或输出待确认事项，不擅自接入外部写入、支付、部署或生产资源。
